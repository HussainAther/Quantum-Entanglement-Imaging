# Literature Notes (Quantum Tensegrity + Stability)

This folder contains short, practical notes on references related to:

- tensegrity stability (rigidity, mechanisms, self-stress, prestress stability)
- biotensegrity / cell mechanics as tensegrity
- modeling frameworks (SVD of equilibrium matrix, stiffness matrices)
- analogies to atomic/nuclear stability charts

## References currently tracked

### Core tensegrity mechanics
- **Fraternali & Rimoli — _Tensegrity Systems_ (book / notes PDF)**
  - Focus: formal stability criteria; equilibrium matrix; SVD; mechanisms vs self-stress.
  - Why it matters: directly supports a “remove-one-cable → does it collapse?” test.

### Tensegrity + cell mechanics / data-driven modeling

  - Focus: FEM-style modeling; tangent stiffness; stability evaluation; SVD-based analysis.

### Biotensegrity framing
- **“Biotensegrity is the super-stability hypothesis for biology”**
  - Focus: conceptual + mathematical framing of tensegrity stability in biological systems.

### Strain / cytoskeleton modeling example
- **“Ultrasound induced strain cytoskeleton rearrangement: An experimental and simulation study”**
  - Focus: mechanics-driven structural rearrangement; simulation workflow inspiration.

### Misc notes / collections

  - Focus: seed bibliography for the atoms ↔ tensegrity analogy.

## Conventions for notes

For each reference, create a file named:

`<year>_<firstauthor>_<shorttitle>.md`

Each note should include:
1. Citation (full)
2. Key claims (3–7 bullets)
3. Definitions or equations we may reuse
4. How it connects to our repo goals (stability chart / cable removal / quantum analogy)
